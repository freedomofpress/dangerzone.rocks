*Edited on 2027/07/30 to provide the previously missing Windows binary.*

This release includes various new features, stability improvements, and security fixes. You are strongly advised to update to this new version.

### Breaking changes

* Our Windows code-signing certificate has changed in this release. Due to recent changes in the Windows signing policies, we had to switch CA providers and certificate types. We expect that users should be able to install Dangerzone **without any warning screens**, but if you encounter one, please let us know, either with a [GitHub issue](https://github.com/freedomofpress/dangerzone/issues/new/choose) or via email to [support@dangerzone.rocks](mailto:support@dangerzone.rocks).
* Our Linux packages no longer include the container image by default. For both new and existing users, the container image will be downloaded at first use, and then will be kept up to date. If your installation is in an air-gapped environment, or if you prefer not to get updates, you can install the `dangerzone-full` variant ([#1069](https://github.com/freedomofpress/dangerzone/issues/1069)) instead.

  This is a **breaking change** if you are using the Linux CLI, as it no longer has a ready-to-use conversion sandbox. New installations must initialize the sandbox once with `dangerzone-image upgrade` (or run the GUI, which prompts for the download) before `dangerzone-cli` can convert documents. Users of the `dangerzone-full` package or users who already have an image installed are unaffected.

### Highlights

* Optical character recognition in the sanitized PDF is now happening in parallel. Internal tests have shown a speedup of up to x6, but your mileage may vary ([#1329](https://github.com/freedomofpress/dangerzone/issues/1329)).
* It is now possible to convert another set of documents after the first batch ([#549](https://github.com/freedomofpress/dangerzone/issues/549)), or add more documents to an ongoing conversion ([#1464](https://github.com/freedomofpress/dangerzone/pull/1464)).
* You can now install Dangerzone from the Microsoft Store and follow updates automatically.

### Fixed

* User-selected output directory is now remembered across sessions ([#1123](https://github.com/freedomofpress/dangerzone/issues/1123)).
* (MacOS, Windows) The theme correctly detects dark/light mode changes ([#1238](https://github.com/freedomofpress/dangerzone/issues/1238)).
* (Linux) The default PDF reader selection is now fixed ([#814](https://github.com/freedomofpress/dangerzone/issues/814)).
* (Linux) HWP and ODF formats are now linked correctly to Dangerzone on Linux ([#646](https://github.com/freedomofpress/dangerzone/issues/646)).
* (Linux) Searching for applications to handle PDFs is now handled better, thanks to an updated way to look for Desktop entries in `XDG_DATA_DIRS` ([#1413](https://github.com/freedomofpress/dangerzone/issues/1413)).

### Platform changes

* Ubuntu: Add support for Ubuntu 26.04 (Resolute Raccoon) ([#1467](https://github.com/freedomofpress/dangerzone/issues/1467)) and drop support for Ubuntu 25.04 (Plucky Puffin), as it has reached end of life ([#1468](https://github.com/freedomofpress/dangerzone/issues/1468)).
* Windows 10: Add a deprecation warning ([#1357](https://github.com/freedomofpress/dangerzone/issues/1357)).
* Fedora: Add support for Fedora 44 ([#1462](https://github.com/freedomofpress/dangerzone/issues/1462)) and drop support for Fedora 41 and 42, as they have reached end of life.
* Debian: Drop support for Debian bull’s-eye ([#1482](https://github.com/freedomofpress/dangerzone/issues/1482)).
